# 🧪 Ejercicios: ¿Phishing o legítimo?

Después de leer la [guía para reconocer phishing](./reconocer-phishing), pon a prueba tu ojo con estos ejercicios interactivos.

Lee cada correo con calma y decide si es **phishing** o **legítimo**. Después de responder, verás las señales que debías observar. No te preocupes por equivocarte: la idea es practicar.

:::tip
Recuerda: la señal más útil casi nunca es un solo detalle, sino la **combinación** de varios indicios pequeños.
:::

<PhishingQuiz />

:::note
Estos correos son ejemplos de práctica. Si recibes uno real que te parezca sospechoso, no interactúes con él y repórtalo con el botón **Report Phishing** de Outlook.
:::
